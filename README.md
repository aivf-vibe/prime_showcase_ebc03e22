# Nidum AI Landing Page

A modern, responsive landing page for Nidum AI built with Next.js and Tailwind CSS.

## Features

- Modern, responsive design with dark theme and gradient background
- Interactive navigation with smooth scrolling
- Optimized for performance and SEO
- Built with Next.js 15 and Tailwind CSS
- Fully customizable components
- TypeScript support
- Geist font integration

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/page.tsx` - Main landing page component with sections:
  - Navigation
  - Hero section
  - Features
  - Contact
  - Footer
- `src/app/layout.tsx` - Root layout with metadata and font configuration
- `src/app/globals.css` - Global styles and Tailwind configuration

## Built With

- [Next.js](https://nextjs.org/) - The React Framework
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework
- [TypeScript](https://www.typescriptlang.org/) - JavaScript with syntax for types
- [Geist Font](https://vercel.com/font) - Modern, optimized font family

## Deployment

The project can be deployed to any platform that supports Next.js applications. For the easiest deployment experience, we recommend using [Vercel](https://vercel.com), the platform created by the creators of Next.js.
